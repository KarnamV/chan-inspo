# chan-inspo

A Jackie Chan–inspired isometric 3D action roguelite, built in Godot 4.7. A martial artist trapped in a demon realm fights with whatever is lying around: chairs, ladders, lanterns. The Sheep talisman lets him possess a downed demon.

- Concept: [`design/concept.md`](design/concept.md)
- Design artifacts and conventions: [`design/README.md`](design/README.md)
- The earlier 2.5D sprite version (Demon Realm Escape v1) is preserved in [`archive/demon-realm-escape/`](archive/demon-realm-escape/).

Art is produced with the local `ai-gamedev-pipeline` skill: concept image, textured TRELLIS.2 mesh, UniRig rig and Quaternius animations.
